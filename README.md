# Blood Link | بوابة إنقاذ الحياة (الإصدار المطور v4)

منصة تفاعلية ثلاثية الأبعاد للتبرع بالدم وربط المتبرعين بالمرضى والمستشفيات في جميع محافظات مصر الـ 27 مع توثيق الرقم القومي.

## التحديثات المضافة في v4
- إضافة حقل **الرقم القومي (14 رقم)** في بوابة المتبرع وبوابة المتلقي مع التحقق التلقائي من صحة الطول والأرقام.
- عرض الرقم القومي بشكل مقنّع وآمن (`3010915•••1234`) على بطاقة المتبرع ثلاثية الأبعاد، في صورة الـ PNG المحمّلة، وفي قائمة الحالات برادار المتلقين.
- دعم كامل للـ 27 محافظة مصرية باللغتين العربية والإنجليزية.
